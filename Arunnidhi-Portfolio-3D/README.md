# Arunnidhi 3D Portfolio

A 3D animated personal portfolio using the UI/UX principles from the supplied skill package.

## Highlights
- CSS 3D rotating cube hero
- Cursor-reactive 3D scene
- Animated orbiting skill system
- 3D tilt interaction
- Holographic FocusGuard project card
- Animated background particles
- Responsive layout
- Keyboard skip link and focus states
- `prefers-reduced-motion` support
- No build step or framework required

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to a repository, then enable:
**Settings → Pages → Deploy from a branch → main → /root**

The site uses only HTML/CSS/JavaScript plus a Google Fonts import.
