# FocusGuard AI

Predicts whether an Instagram session is likely **intentional** (opened for a
specific purpose) or **habitual** (reflexive/distraction-driven), based only
on signals available *before* the session starts — no peeking at how long the
session lasted or why the user says they opened it.

## How to run

```bash
pip install -r requirements.txt
python train.py   # trains the model, prints results, saves focusguard_model.pkl
python app.py      # launches the GUI using the saved model
```

## Data

`instagram_usage_data.csv` — self-logged Instagram sessions with columns:
`date, time, previous_app, instagram_notification, instagram_opens_30min,
instagram_opens_2hr, previous_instagram_duration, current_session_duration,
reason, intentional, wanted_to_stop`

Two columns — `reason` and `wanted_to_stop` — are **deliberately excluded**
from the model. Both are recorded at the same time as the `intentional`
label and effectively restate it (e.g. `reason: habit` almost always implies
`intentional: no`). Including them would inflate accuracy through leakage,
not genuine prediction.

## Model & results

- RandomForestClassifier, tuned with `GridSearchCV` over
  `n_estimators`, `max_depth`, `min_samples_leaf`.
- Evaluated with **5-fold stratified cross-validation** rather than a single
  train/test split — with ~290 rows, one 80/20 split has a test set of ~58
  rows, where each row swings "accuracy" by ~1.7 points. CV gives a more
  stable estimate.

| Metric | Value |
|---|---|
| Dataset size | 287 logged sessions |
| Majority-class baseline | 57.5% |
| **Cross-validated accuracy** | **66.6%** |
| Improvement over baseline | +9.1 points |

**Honest caveat:** this is a small, single-person dataset. 66.6% is a real,
leakage-free result — but not a strong one. The biggest lever for improving
it further is more logged data (ideally 800–1500+ rows across more varied
days/contexts), not more model tuning. See feature importances below for
what the model currently relies on most.

Top features by importance: notification present, time since last
Instagram session, previous session's duration, hour of day.

## Project structure

```
train.py                    # loads data, engineers features, tunes + trains,
                             # saves model + preprocessor to focusguard_model.pkl
app.py                       # loads the saved model, runs the Tkinter GUI
instagram_usage_data.csv     # logged session data
focusguard_model.pkl         # saved model artifact (generated by train.py)
requirements.txt
```

## Limitations

- Small dataset (n=287) limits achievable accuracy and generalizability.
- Single-user data — patterns may not transfer to other people's habits.
- `previous_app` categories are limited to what appeared in the logged data;
  unseen apps at inference time are handled via `handle_unknown="ignore"`
  but contribute no learned signal.
